Detailed Description

Provides MySQL connections (pooled when available).

Usage patterns:

  • Call init_pool() once at startup (recommended).
  • Call connect() wherever a DB connection is needed.
Warning
Credentials are currently hard-coded for development/demo use. For production, use environment variables or a secrets manager.

◆ connect()

app.database_connection.DatabaseConnection.connect (   self)

Return a MySQL connection.

If a pool is initialized, this borrows a connection from the pool. Otherwise, falls back to creating a direct connection (legacy behavior).

During a Flask request, the connection is registered for automatic cleanup at request teardown (returning it to the pool).
